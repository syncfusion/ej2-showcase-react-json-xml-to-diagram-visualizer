# Essential JS 2 for React - JSON and XML to Diagram Layout
A JSON/XML-to-Diagram Visualizer converts JSON or XML data into interactive diagrams, helping users easily understand data structures, hierarchies, and relationships visually

## Prerequisite 

Install Node version - 22.14.0 from https://nodejs.org/en/download/ 

## To Install all packages

Use the below command to install all dependent packages.

```
npm install
```

## To Run the application

Run `npm start` for a dev server. Navigate to `http://localhost:8080/`.
